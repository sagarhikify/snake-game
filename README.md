# 🐍 Snake Game

> A sleek, responsive Snake game that works everywhere — desktop, mobile, tablet. No dependencies, pure vanilla JS.

![Snake Game Preview](https://img.shields.io/badge/Play-Now-brightgreen?style=for-the-badge&logo=gamepad)
![Vanilla JS](https://img.shields.io/badge/Vanilla-JS-yellow?style=for-the-badge&logo=javascript)
![Mobile Ready](https://img.shields.io/badge/Mobile-Ready-pink?style=for-the-badge&logo=android)

---

## ✨ Features

| Feature | Details |
|---------|---------|
| 🎮 **Cross-platform** | Works on Chrome, Safari, Firefox, Edge — desktop & mobile |
| 📱 **Touch controls** | Swipe anywhere on canvas + on-screen D-pad (auto-shows on mobile) |
| ⌨️ **Keyboard support** | Arrow keys / WASD |
| 💾 **High score persistence** | Saved to localStorage — survives browser restarts |
| ⚡ **Progressive difficulty** | Speed increases as you score |
| 🎨 **Neon aesthetic** | Dark theme with glow effects |
| 📦 **Zero dependencies** | Single HTML file, ~3KB gzipped |

## 🚀 Play Now

**Option 1:** Open `snake.html` directly in any browser

**Option 2:** Deploy to GitHub Pages (free hosting)
1. Go to repo Settings → Pages
2. Source: "Deploy from a branch" → `main` / `/root`
3. Your game lives at `https://sagarhikify.github.io/snake-game`

## 🎯 Controls

| Platform | Controls |
|----------|----------|
| **Desktop** | `↑ ↓ ← →` or `W A S D` |
| **Mobile/Tablet** | Swipe on canvas **or** tap on-screen buttons |

## 🛠 Tech Stack

- **HTML5 Canvas** — smooth 60fps rendering
- **Vanilla ES6+ JavaScript** — no frameworks, no build step
- **CSS Grid/Flexbox** — responsive layout
- **localStorage** — high score persistence

## 🎮 Gameplay

```
Eat the neon food  →  Grow longer  →  Avoid walls & yourself  →  Survive as long as possible
```

Speed increases every 10 points. High score saved automatically.
